# Phase-1 Rerun Interruption Recovery Record

## Event

On 2026-08-26, the interactive execution sessions hosting the primary
`m0_seed520003` and `m1_seed520003` processes were terminated before either
process wrote its final `run.json`. No kernel OOM, NVIDIA Xid, disk-capacity,
NaN/Inf, or checkpoint-write error was found. The jobs had not been detached
from the interactive control sessions.

The last complete durable boundary for both runs is update 1000. The complete
checkpoints include the model, AdamW state, update/sample position, sampler
order hash, Python/NumPy/Torch CPU/Torch CUDA RNG states, and the dedicated
flow and loader generator states. Their recorded SHA-256 values are:

- M0: `6a39c8e0bca1d6720dc9bdcc976fb5144ede9c8608947e828e2fa964729983b4`
- M1: `d24195ce3bcd6cfcfd0749ac95f36c9fdade522c4b150a7d51a0f90c316d8c4d`

## Recovery procedure

Both runs resume from update 1000 and execute updates 1001 through 5000 with
the frozen method, seed, sample order, optimizer, schedule, precision,
validation schedule, and checkpoint schedule unchanged. The continuation
runner refuses any checkpoint outside the frozen primary checkpoint schedule,
audits exact restoration, and reapplies the checkpoint RNG state after building
the validation cache.

The already durable physical-space validation arrays at updates 0, 250, 500,
and 1000 are retained. Their physical metrics are reconstructed directly from
stored predictions, targets, and masks. The pre-interruption fixed-flow MSE is
marked unavailable because the arrays do not contain the flow-loss tensor; it
is not inferred or fabricated. Later scheduled validation is generated by the
continued process normally.

The original processes durably wrote detailed traces for updates 1001--1005.
The recovered processes must reproduce those traces exactly. A mismatch is a
scientific stop condition for the affected run.

Continuation jobs are hosted in persistent `tmux` sessions so that subsequent
interactive messages cannot terminate training.

This is an operational interruption recovery only. It changes no Phase-1
scientific protocol, method definition, seed, data, budget, metric, or decision
threshold.
